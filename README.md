# Предобработка данных о рынке видеоигр

## О проекте
Глубокая очистка и категоризация исторических данных о продажах видеоигр за 2000–2013 годы.

**Цель:** подготовить чистый датасет для дальнейшего анализа продуктовых метрик.

## Данные
16 956 строк: продажи, платформы, жанры, оценки критиков и пользователей, рейтинг ESRB.

## Стек
- Python, Pandas
- to_numeric, заполнение пропусков по группам, str.replace / str.lower, pd.cut

## Что сделано

1. **Заголовки** — приведены к snake_case.
2. **Типы данных** — убраны текстовые заглушки (tbd, unknown), продажи и оценки переведены в float, годы — в int.
3. **Пропуски**
   - Критические поля (name, genre, year_of_release) — удалены единичные пропуски.
   - Региональные продажи — заполнены средними по платформе и году.
   - ESRB — выделена категория UNKNOWN.
4. **Дубликаты** — убраны скрытые дубли в жанрах и 235 явных строк-дублей.
5. **Потери** — итого 3.02% (512 строк).

## Результат
- Чистый срез 2000–2013 гг.: 12 781 строка.
- Сегментация игр по оценкам пользователей и критиков.
- Топ-7 платформ по количеству релизов.
